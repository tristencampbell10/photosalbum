# Photos Album

This project is a React and TypeScript photo album built with Vite.

## Run on Replit

Use the **Start application** workflow. It runs:

```sh
npm run dev
```

The Vite development server listens on `0.0.0.0:5000` and allows Replit's proxied preview hosts.

## Other commands

- `npm run build` creates a production build.
- `npm run lint` runs the TypeScript type check.
